# Building Described Collections
The most essential step in using MatchMaker is creating collections: a unique format that makes possible the matching of knowledge across a variety of sources. As covered in the introduction, collections are made up of elements. 



:::info
**What are elements?**

Elements exist under other elements in the collection hierarchy and can contain any number of additional elements. The lowest level of that hierarchy, elements that contain no additional elements, are referred to as "Leaf Elements", are those that are described by Palet statements (refer to “How to Describe Elements”).

Every element must contain a name and type.

**Name**:
Self-explanatory; name for the element (e.g. Unit 1)

**Type**:
1. **Learning Resource:**
An online curriculum, book, activity, reference, or other source of information.
2. **Competency Statement:**
A certification, examination, or some other source of knowledge verification 
3. **Curriculum:**
The scope and sequence of a class or course.
4. **Other:**
Anything else!



:::

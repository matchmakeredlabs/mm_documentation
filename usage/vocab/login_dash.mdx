Click on any of the above buttons to learn more about that section. Here’s a quick summary:
## Create
Create and edit collections you have access to, either creating or modifying a hierarchy.
## Browse & Describe
View all available collections, and start describing elements in collections you have such access to.
## Generate Report
Gain insights from matching collections and custom sets to one another. Additionally, you can create and edit custom edits in this section.
## Administer
The center for all permission management. Here you can manage users, organizations you have access to, and groups.

/customers

The customers API manages MatchMaker customer accounts. A customer owns projects, defines account limits, and assigns customer-level roles to users and groups. In the MatchMaker user interface, customers are presented as organizations.

All requests require an authenticated bearer token.

Table of Contents​

EndpointDescription
GET - All CustomersRetrieve the customers the caller can read.
GET - Customer by IDRetrieve one customer by its ID.
POST - Create CustomerCreate a managed customer account.
PUT - Update CustomerReplace an existing customer account.
DELETE - Remove CustomerDelete a customer account.

GET - All Customers​

Endpoint​

GET https://matchmakeredlabs.net/api/customers

Notes​

Returns customers on which the caller has ReadCustomer privilege. Global administrators and users with ReadCustomer on the adminorganization ACL scope can list all customers.

The response is an object containing an items array.

Request​

Query Parameters​

Optional query parameters perform exact property matches. Multiple different parameters are combined with AND. For example:

GET /api/customers?customerKind=managed&canUseApi=true

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-X GET "https://matchmakeredlabs.net/api/customers"
const response = await fetch("https://matchmakeredlabs.net/api/customers", {
    headers: { Authorization: `Bearer ${TOKEN}` }
});
const customers = await response.json();
import requests

response = requests.get(
    "https://matchmakeredlabs.net/api/customers",
    headers={"Authorization": f"Bearer {token}"}
)
customers = response.json()

GET - Customer by ID​

Endpoint​

GET https://matchmakeredlabs.net/api/customers/{customerId}

Notes​

The caller must have ReadCustomer privilege on the requested customer or on the adminorganization ACL scope.

Returns 404 Not Found when the ID does not exist and 403 Forbidden when the caller cannot read the customer.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
customerIdstringYesCustomer UUID.

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-X GET "https://matchmakeredlabs.net/api/customers/84c45a40-c55d-4278-9a70-11432f13c1e2"
const customerId = "84c45a40-c55d-4278-9a70-11432f13c1e2";
const response = await fetch(
    `https://matchmakeredlabs.net/api/customers/${customerId}`,
    { headers: { Authorization: `Bearer ${TOKEN}` } }
);
const customer = await response.json();
import requests

response = requests.get(
    f"https://matchmakeredlabs.net/api/customers/{customer_id}",
    headers={"Authorization": f"Bearer {token}"}
)
customer = response.json()

POST - Create Customer​

Endpoint​

POST https://matchmakeredlabs.net/api/customers

Notes​

Creating a customer requires global administration privilege or WriteCustomer privilege on the adminorganization ACL scope. The server generates the customer UUID. Do not put an ID in the URL.

customerKind may be omitted and defaults to managed. Personal customers normally originate in self-registration. If customerKind is personal, personalOwnerId is required and the server ensures that the personal owner retains the owner role.

Request​

Query Parameters​

None.

Request Body​

{
    "name": "ExampleOrganization",
    "description": "Example customer account",
    "roles": [
        {
            "id": "user@example.com",
            "role": "owner"
        }
    ],
    "allowedProjects": 10,
    "usersPerProject": 50,
    "elePerCollection": 5000,
    "canUseApi": true,
    "maxCollections": 100,
    "reportingCapabilities": "basic"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/customers" \
--data '{
  "name": "ExampleOrganization",
  "description": "Example customer account",
  "roles": [{"id": "user@example.com", "role": "owner"}],
  "allowedProjects": 10,
  "usersPerProject": 50,
  "elePerCollection": 5000,
  "canUseApi": true,
  "maxCollections": 100,
  "reportingCapabilities": "basic"
}'
const response = await fetch("https://matchmakeredlabs.net/api/customers", {
    method: "POST",
    headers: {
        Authorization: `Bearer ${TOKEN}`,
        "Content-Type": "application/json"
    },
    body: JSON.stringify(customer)
});
const createdCustomer = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/customers",
    headers={"Authorization": f"Bearer {token}"},
    json=customer
)
created_customer = response.json()

PUT - Update Customer​

Endpoint​

PUT https://matchmakeredlabs.net/api/customers/{customerId}

Notes​

The caller must have WriteCustomer privilege on the customer or on the adminorganization ACL scope. PUT replaces the customer representation rather than applying a partial patch, so include all required persisted properties. The body must include an id that exactly matches {customerId}.

The read-only properties beginning with _ may be omitted. If they are sent, the server removes them before saving.

If roles is omitted, the server preserves the existing role assignments. For personal customers, protected owner roles and protected account settings cannot be removed by ordinary customer members.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
customerIdstringYesCustomer UUID. Must match the id in the request body.

Request Body​

{
    "id": "84c45a40-c55d-4278-9a70-11432f13c1e2",
    "type": "customer",
    "customerKind": "managed",
    "name": "ExampleOrganization",
    "description": "Updated customer account",
    "roles": [
        {
            "id": "user@example.com",
            "role": "owner"
        }
    ],
    "allowedProjects": 15,
    "usersPerProject": 50,
    "elePerCollection": 5000,
    "canUseApi": true,
    "maxCollections": 100,
    "reportingCapabilities": "full"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-X PUT "https://matchmakeredlabs.net/api/customers/84c45a40-c55d-4278-9a70-11432f13c1e2" \
--data @customer.json
const response = await fetch(
    `https://matchmakeredlabs.net/api/customers/${customer.id}`,
    {
        method: "PUT",
        headers: {
            Authorization: `Bearer ${TOKEN}`,
            "Content-Type": "application/json"
        },
        body: JSON.stringify(customer)
    }
);
const updatedCustomer = await response.json();
import requests

response = requests.put(
    f"https://matchmakeredlabs.net/api/customers/{customer['id']}",
    headers={"Authorization": f"Bearer {token}"},
    json=customer
)
updated_customer = response.json()

DELETE - Remove Customer​

Endpoint​

DELETE https://matchmakeredlabs.net/api/customers/{customerId}

Notes​

Deleting a customer requires WriteCustomer privilege on the customer or on the adminorganization ACL scope. Projects that refer to the deleted customer are not deleted or updated; their customerId references become orphaned.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
customerIdstringYesCustomer UUID.

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-X DELETE "https://matchmakeredlabs.net/api/customers/84c45a40-c55d-4278-9a70-11432f13c1e2"
await fetch(`https://matchmakeredlabs.net/api/customers/${customerId}`, {
    method: "DELETE",
    headers: { Authorization: `Bearer ${TOKEN}` }
});
import requests

response = requests.delete(
    f"https://matchmakeredlabs.net/api/customers/{customer_id}",
    headers={"Authorization": f"Bearer {token}"}
)

Sample Response​

{
    "id": "84c45a40-c55d-4278-9a70-11432f13c1e2"
}

Common Status Codes​

StatusMeaning
200 OKThe operation succeeded.
400 Bad RequestThe URL, body, query, or customer properties are invalid.
401 UnauthorizedAuthentication is missing or invalid.
403 ForbiddenThe caller lacks the required privilege.
404 Not FoundThe requested customer does not exist.
409 ConflictA record with the generated or supplied ID conflicts with an existing record.

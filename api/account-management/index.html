Account management

These endpoints create and maintain a MatchMaker user account. Registration and password-reset endpoints are anonymous. Changing account details or deleting an account requires an authorization token.

The user's normalized email or username is also the permanent user ID. MatchMaker does not currently provide an endpoint for changing it.

Table of Contents​

EndpointDescription
POST - Start Account RegistrationSend an email-confirmation link for a new account.
POST - Confirm Account RegistrationConfirm the email and create the account.
POST - Register ImmediatelyCreate an account without email confirmation.
POST - Request Password ResetSend a password-reset link.
POST - Confirm Password ResetSet a new password using a reset token.
POST - Change PasswordChange the authenticated user's password.
POST - Change Full NameChange the authenticated user's display name.
DELETE - Delete AccountPermanently delete the authenticated user's account.

POST - Start Account Registration​

Endpoint​

POST https://matchmakeredlabs.net/api/account-registrations

Notes​

This is the recommended self-registration flow used by the MatchMaker interface. It creates a pending registration and emails a confirmation link; it does not create the user until the confirmation endpoint succeeds.

The email is normalized to lowercase. A new request for the same email replaces any previous pending registration. By default, the confirmation link expires after 24 hours. The request fails with 409 Conflict if the user already exists and 503 Service Unavailable if confirmation email is disabled.

The password must be at least eight characters and contain an uppercase letter, lowercase letter, digit, and special character. It cannot begin or end with whitespace. fullName is required. customerName is optional and defaults to a name derived from fullName.

Request​

Query Parameters​

None.

Request Body​

ParameterTypeRequiredDescription
emailstringYesEmail address or username for the account. name and username are accepted aliases.
fullNamestringYesUser's display name.
passwordstringYesPassword satisfying the rules above.
customerNamestringNoName for the personal customer created with the account.
{
    "email": "alex@example.com",
    "fullName": "Alex Morgan",
    "password": "ExamplePassword1!",
    "customerName": "organization_Alex_Morgan"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/account-registrations" \
--data '{
  "email": "alex@example.com",
  "fullName": "Alex Morgan",
  "password": "ExamplePassword1!"
}'
const response = await fetch(
    "https://matchmakeredlabs.net/api/account-registrations",
    {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
            email: "alex@example.com",
            fullName: "Alex Morgan",
            password: "ExamplePassword1!"
        })
    }
);
const result = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/account-registrations",
    json={
        "email": "alex@example.com",
        "fullName": "Alex Morgan",
        "password": "ExamplePassword1!"
    }
)
result = response.json()

Sample Response​

{
    "email": "alex@example.com",
    "confirmationRequired": true
}

POST - Confirm Account Registration​

Endpoint​

POST https://matchmakeredlabs.net/api/account-registrations/confirm

Notes​

The token comes from the confirmation link emailed by the registration request. A successful request creates both the user and a personal customer account, assigns the user the customer's owner role, and consumes the pending registration.

An expired registration returns 410 Gone. A missing, invalid, or already-confirmed registration returns 404 Not Found.

Request​

Query Parameters​

None.

Request Body​

ParameterTypeRequiredDescription
tokenstringYesAccount-confirmation token from the emailed link.
{
    "token": "0123456789abcdef0123456789abcdef"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/account-registrations/confirm" \
--data '{"token":"0123456789abcdef0123456789abcdef"}'
const response = await fetch(
    "https://matchmakeredlabs.net/api/account-registrations/confirm",
    {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ token })
    }
);
const account = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/account-registrations/confirm",
    json={"token": confirmation_token}
)
account = response.json()

Sample Response​

{
    "userId": "alex@example.com",
    "customerId": "84c45a40-c55d-4278-9a70-11432f13c1e2"
}

POST - Register Immediately​

Endpoint​

POST https://matchmakeredlabs.net/api/register

Notes​

This anonymous endpoint creates the user and personal customer immediately, without verifying the email address. The email-confirmed account-registration flow above is preferred for normal user-facing registration.

The same full-name, password, username, duplicate-user, and optional customer-name rules apply. The user ID is read from name; username is accepted as an alias.

Request​

Query Parameters​

None.

Request Body​

{
    "name": "alex@example.com",
    "fullName": "Alex Morgan",
    "password": "ExamplePassword1!",
    "customerName": "organization_Alex_Morgan"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/register" \
--data '{
  "name": "alex@example.com",
  "fullName": "Alex Morgan",
  "password": "ExamplePassword1!"
}'
const response = await fetch("https://matchmakeredlabs.net/api/register", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
        name: "alex@example.com",
        fullName: "Alex Morgan",
        password: "ExamplePassword1!"
    })
});
const account = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/register",
    json={
        "name": "alex@example.com",
        "fullName": "Alex Morgan",
        "password": "ExamplePassword1!"
    }
)

POST - Request Password Reset​

Endpoint​

POST https://matchmakeredlabs.net/api/password-resets

Notes​

This endpoint is anonymous and always returns the same success message, whether or not the email belongs to an account. This prevents callers from discovering registered accounts.

A new request invalidates previous reset tokens for the user. The emailed token expires after 15 minutes by default and can be used only once. In local loopback test mode only, the response may also contain resetToken.

Request​

Query Parameters​

None.

Request Body​

ParameterTypeRequiredDescription
emailstringYesAccount email or username.
{
    "email": "alex@example.com"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/password-resets" \
--data '{"email":"alex@example.com"}'
const response = await fetch(
    "https://matchmakeredlabs.net/api/password-resets",
    {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ email: "alex@example.com" })
    }
);
const result = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/password-resets",
    json={"email": "alex@example.com"}
)
result = response.json()

Sample Response​

{
    "message": "If an account exists for that email, a reset link has been sent."
}

POST - Confirm Password Reset​

Endpoint​

POST https://matchmakeredlabs.net/api/password-resets/confirm

Notes​

This endpoint is anonymous. The reset token comes from the emailed link. The new password must satisfy the normal password rules and must differ from the current password.

Successful confirmation consumes the token and invalidates any other pending resets for the user. An invalid or previously used token returns 404 Not Found; an expired token returns 410 Gone.

Request​

Query Parameters​

None.

Request Body​

{
    "token": "password-reset-token",
    "newPassword": "NewExamplePassword2!"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/password-resets/confirm" \
--data '{
  "token": "password-reset-token",
  "newPassword": "NewExamplePassword2!"
}'
const response = await fetch(
    "https://matchmakeredlabs.net/api/password-resets/confirm",
    {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
            token,
            newPassword: "NewExamplePassword2!"
        })
    }
);
const result = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/password-resets/confirm",
    json={
        "token": reset_token,
        "newPassword": "NewExamplePassword2!"
    }
)
result = response.json()

Sample Response​

{
    "userId": "alex@example.com"
}

POST - Change Password​

Endpoint​

POST https://matchmakeredlabs.net/api/users/{userId}/change-password

Notes​

Requires authentication. A user can change only their own password; {userId} must match the authenticated user, even for an administrator. The current password must be correct, and the new password must satisfy the normal password rules and differ from the current password.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
userIdstringYesAuthenticated user's ID.

Request Body​

{
    "currentPassword": "ExamplePassword1!",
    "newPassword": "NewExamplePassword2!"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/users/alex@example.com/change-password" \
--data '{
  "currentPassword": "ExamplePassword1!",
  "newPassword": "NewExamplePassword2!"
}'
const userId = "alex@example.com";
const response = await fetch(
    `https://matchmakeredlabs.net/api/users/${encodeURIComponent(userId)}/change-password`,
    {
        method: "POST",
        headers: {
            Authorization: `Bearer ${TOKEN}`,
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            currentPassword: "ExamplePassword1!",
            newPassword: "NewExamplePassword2!"
        })
    }
);
const result = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/users/alex@example.com/change-password",
    json={
        "currentPassword": "ExamplePassword1!",
        "newPassword": "NewExamplePassword2!"
    },
    headers={"Authorization": f"Bearer {token}"}
)
result = response.json()

Sample Response​

{
    "id": "alex@example.com"
}

POST - Change Full Name​

Endpoint​

POST https://matchmakeredlabs.net/api/users/{userId}/change-full-name

Notes​

Requires authentication. A user can change only their own full name; {userId} must match the authenticated user. The value is trimmed and cannot be empty.

Changing fullName does not change the user's ID, username, email, or the name of an existing personal customer.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
userIdstringYesAuthenticated user's ID.

Request Body​

{
    "fullName": "Alexandra Morgan"
}

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-X POST "https://matchmakeredlabs.net/api/users/alex@example.com/change-full-name" \
--data '{"fullName":"Alexandra Morgan"}'
const userId = "alex@example.com";
const response = await fetch(
    `https://matchmakeredlabs.net/api/users/${encodeURIComponent(userId)}/change-full-name`,
    {
        method: "POST",
        headers: {
            Authorization: `Bearer ${TOKEN}`,
            "Content-Type": "application/json"
        },
        body: JSON.stringify({ fullName: "Alexandra Morgan" })
    }
);
const result = await response.json();
import requests

response = requests.post(
    "https://matchmakeredlabs.net/api/users/alex@example.com/change-full-name",

    headers={"Authorization": f"Bearer {token}"}
)
result = response.json()

Sample Response​

{
    "id": "alex@example.com",
    "fullName": "Alexandra Morgan"
}

DELETE - Delete Account​

Endpoint​

DELETE https://matchmakeredlabs.net/api/users/{userId}

Notes​

An authenticated user may delete their own account. A global administrator with WriteUser may also delete a user.

Deleting a user also deletes personal customers owned by that user and removes the user from groups and from project and customer role assignments. Deleting a personal customer does not delete its projects; those projects retain an orphaned customerId. This operation cannot be undone.

Request​

Query Parameters​

None.

Path Parameters​

ParameterTypeRequiredDescription
userIdstringYesUser account to delete.

Sample Request​

  • cURL
  • JavaScript
  • Python
curl \
-H "Authorization: Bearer $TOKEN" \
-X DELETE "https://matchmakeredlabs.net/api/users/alex@example.com"
const userId = "alex@example.com";
const response = await fetch(
    `https://matchmakeredlabs.net/api/users/${encodeURIComponent(userId)}`,
    {
        method: "DELETE",
        headers: { Authorization: `Bearer ${TOKEN}` }
    }
);
const result = await response.json();
import requests

response = requests.delete(
    "https://matchmakeredlabs.net/api/users/alex@example.com",
    headers={"Authorization": f"Bearer {token}"}
)
result = response.json()

Sample Response​

{
    "id": "alex@example.com"
}

Common Status Codes​

StatusMeaning
200 OKThe operation succeeded.
400 Bad RequestRequired values are missing or fail validation.
401 UnauthorizedAuthentication or the current password is invalid.
403 ForbiddenThe authenticated user cannot modify the requested account.
404 Not FoundThe user, registration, or reset token was not found.
409 ConflictThe account already exists.
410 GoneA registration or password-reset token has expired.
503 Service UnavailableRequired email delivery is disabled.

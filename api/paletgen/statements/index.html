PaletGen statements

These endpoints manage generated statements, review approvals, archived merge sources, and merge audit records. All requests require Authorization: Bearer <token> and project read or write access as appropriate.

Endpoint summary​

MethodEndpointDescription
GET/api/paletgen/statementsList project statements.
GET/api/paletgen/statements/{statementId}Retrieve a statement.
POST/api/paletgen/statementsCreate a statement.
PUT/api/paletgen/statements/{statementId}Edit a statement or its status.
DELETE/api/paletgen/statements/{statementId}Delete a statement.
POST/api/paletgen/search/statementsVector-search statements.
POST / DELETE/api/paletgen/statements/approve/{statementId}Add or remove the caller's approval.
POST/api/paletgen/statements/undo-merge/{mergeRecordId}Undo a merge.
POST/api/paletgen/statements/unarchive/{statementId}Restore an archived statement.
GET/api/paletgen/statements/merge-records[/{mergeRecordId}]List or retrieve applied merges.
GET/api/paletgen/statements/merge-decisions[/{decisionRecordId}]List or retrieve merge decisions.

GET - List statements​

Notes​

  • Project members should supply projectId; system administrators may omit it to list across projects.
  • Archived statements are hidden by default. Embeddings are always removed from list responses.
  • outputSimilarityScores is enabled by the parameter's presence, even when its value is false.

Request​

Query parameterTypeRequiredDescription
projectIdstringFor project membersLimit results to one project.
includeArchivedbooleanNoInclude statements whose lifecycleStatus is archived. Default false.
outputSimilarityScoresflagNoAdd _similarityScore calculated against the returned statements.

Path parameters: none.

curl -H "Authorization: Bearer $TOKEN" \
  "https://matchmakeredlabs.net/api/paletgen/statements?projectId=project-123&outputSimilarityScores=true"

Sample response​

{
  "items": [
    {
      "id": "statement-101",
      "type": "generated-statement",
      "projectId": "project-123",
      "statement": "Energy can be transferred between objects.",
      "stmtType": "D",
      "lifecycleStatus": "active",
      "status": { "type": "draft" },
      "_similarityScore": 0.82,
      "_canUpdate": true
    }
  ]
}

GET - Statement by ID​

Notes​

  • Requires read access to the statement's project.
  • Unlike list responses, an item response can contain the stored embedding.

Request​

Path parameterTypeRequiredDescription
statementIdstringYesGenerated statement ID.

Query parameters: none.

curl -H "Authorization: Bearer $TOKEN" \
  "https://matchmakeredlabs.net/api/paletgen/statements/statement-101"

Sample response​

{
  "id": "statement-101",
  "type": "generated-statement",
  "projectId": "project-123",
  "statement": "Energy can be transferred between objects.",
  "stmtType": "D",
  "embedding": [0.012, -0.034, 0.056],
  "lifecycleStatus": "active",
  "status": { "type": "draft" },
  "_canUpdate": true
}

POST - Create statement​

Notes​

  • Requires write access to the project in the body.
  • statement is the only field specifically required by this handler. The endpoint does not generate an embedding on create, so callers creating fully searchable records should provide one or use the generation workflow.

Request​

Query parameterTypeRequiredDescription
projectIdstringNoAuthorization fallback when projectId is not present in the body.

Path parameters: none.

Body parameterTypeRequiredDescription
idstringYesStatement ID.
projectIdstringYesOwning PaletGen project.
statementstringYesStatement text.
stmtTypestringNoUsually CU, D, P, or STFk.
embeddingnumber[]NoPrecomputed vector used by vector search.
lifecycleStatusstringNoUsually active or archived.
statusobjectNoReview workflow status.
curl -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "id": "statement-101",
    "projectId": "project-123",
    "statement": "Energy can be transferred between objects.",
    "stmtType": "D",
    "lifecycleStatus": "active",
    "status": { "type": "draft" }
  }' \
  "https://matchmakeredlabs.net/api/paletgen/statements"

Sample response​

{
  "id": "statement-101",
  "type": "generated-statement",
  "projectId": "project-123",
  "statement": "Energy can be transferred between objects.",
  "stmtType": "D",
  "lifecycleStatus": "active",
  "status": { "type": "draft" },
  "_canUpdate": true
}

PUT - Update statement​

Notes​

  • Requires write access to the existing statement's project. projectId cannot be changed.
  • Send the complete statement representation.
  • Changing statement records statementHistory, updates modifiedOn, and regenerates the embedding.
  • A status change adds the previous status to pastStatuses. Changing to accepted_for_review initializes status.additionalInfo.reviewApprovals when omitted.

Request​

Path parameterTypeRequiredDescription
statementIdstringYesStatement ID; it must match the body id.

Query parameters: none.

curl -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -X PUT \
  -d '{
    "id": "statement-101",
    "projectId": "project-123",
    "statement": "Energy transfers between interacting objects.",
    "stmtType": "D",
    "lifecycleStatus": "active",
    "status": { "type": "accepted_for_review" }
  }' \
  "https://matchmakeredlabs.net/api/paletgen/statements/statement-101"

Sample response​

{
  "id": "statement-101",
  "type": "generated-statement",
  "projectId": "project-123",
  "statement": "Energy transfers between interacting objects.",
  "status": {
    "type": "accepted_for_review",
    "dateChanged": "2026-08-20T16:00:00Z",
    "changedByUserId": "reviewer@example.com",
    "additionalInfo": { "reviewApprovals": [] }
  },
  "pastStatuses": [{ "type": "draft" }],
  "_canUpdate": true
}

POST - Search statements​

Notes​

  • Performs vector search and returns up to 1,000 results for the requested offset.
  • Supply either matchText or a previously returned generatedEmbedding. Reusing the embedding avoids generating it again on subsequent pages.
  • Archived statements are excluded unless includeArchived=true.

Request​

Query parameterTypeRequiredDescription
projectIdstringYesLimit and authorize the search for one project.
includeArchivedbooleanNoInclude archived statements. Default false.

Path parameters: none.

Body parameterTypeRequiredDescription
matchTextstringConditionalText to embed and search for.
generatedEmbeddingnumber[]ConditionalExisting query embedding instead of matchText.
offsetintegerNoVector-search page offset. Default 0.
curl -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{"matchText":"energy transfer","offset":0}' \
  "https://matchmakeredlabs.net/api/paletgen/search/statements?projectId=project-123"

Sample response​

{
  "generatedEmbedding": [0.012, -0.034, 0.056],
  "statements": [
    {
      "id": "statement-101",
      "projectId": "project-123",
      "statement": "Energy transfers between interacting objects.",
      "_canUpdate": true
    }
  ],
  "nextOffset": 1,
  "count": 1
}

POST - Add an approval​

Notes​

  • The statement must have status accepted_for_review and the caller must have project write access.
  • Each user may approve a statement once. The action is also appended to approvalHistory.

Request​

Path parameterTypeRequiredDescription
statementIdstringYesStatement to approve.
Query parameterTypeRequiredDescription
projectIdstringYesOwning project ID.
Body parameterTypeRequiredDescription
commentstringNoReview comment.
curl -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -X POST -d '{"comment":"Approved."}' \
  "https://matchmakeredlabs.net/api/paletgen/statements/approve/statement-101?projectId=project-123"

Sample response​

{ "id": "statement-101" }

DELETE - Remove your approval​

Notes​

  • Removes only the current user's approval and records approval_removed in approvalHistory.

Request​

Path parameterTypeRequiredDescription
statementIdstringYesStatement whose approval should be removed.
Query parameterTypeRequiredDescription
projectIdstringYesOwning project ID.
curl -H "Authorization: Bearer $TOKEN" -X DELETE \
  "https://matchmakeredlabs.net/api/paletgen/statements/approve/statement-101?projectId=project-123"

Sample response​

{ "id": "statement-101" }

POST - Undo a merge​

Notes​

  • Requires project write access.
  • Restores the merged source statements, updates affected descriptor associations, and marks the merge record as reverted. A merge that is already reverted cannot be undone again.

Request​

Path parameterTypeRequiredDescription
mergeRecordIdstringYesApplied merge record to reverse.
Query parameterTypeRequiredDescription
projectIdstringYesOwning project ID.

Request body: none.

curl -H "Authorization: Bearer $TOKEN" -X POST \
  "https://matchmakeredlabs.net/api/paletgen/statements/undo-merge/merge-789?projectId=project-123"

Sample response​

{
  "success": true,
  "errorMessage": null,
  "restoredStatementIds": ["statement-102", "statement-103"],
  "updatedDescriptorIds": ["project-descriptor-22"]
}

POST - Unarchive a statement​

Notes​

  • Requires project write access. The statement must belong to the supplied project.

Request​

Path parameterTypeRequiredDescription
statementIdstringYesArchived statement to restore.
Query parameterTypeRequiredDescription
projectIdstringYesOwning project ID.

Request body: none.

curl -H "Authorization: Bearer $TOKEN" -X POST \
  "https://matchmakeredlabs.net/api/paletgen/statements/unarchive/statement-102?projectId=project-123"

Sample response​

{
  "success": true,
  "errorMessage": null,
  "statementId": "statement-102"
}

      "status": "active",
      "mergeOutputType": "new-statement"
